# Triply Web Application

Next.js 16 (App Router) + React 19 + Tailwind CSS 4 web application for destination discovery, custom travel itinerary generation, budget calculation, and interactive route mapping.

For full project overview, features, and structure, see the root [README.md](../README.md).

## Getting Started

```bash
# Install dependencies
npm install

# Run the dev server
npm run dev

# Run linting
npm run lint

# Create production build
npm run build
```
